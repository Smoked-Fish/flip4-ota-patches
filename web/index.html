Your browser isn't supported. Use a Chromium-based browser instead.

  • Back up the phone first. Flashing can brick a phone. Take the full eMMC backup or a partial backup.
  • On Windows the browser needs the WinUSB driver on the phone in EDL mode: download the driver helper, unzip it and run install-edl-driver.bat with the phone in EDL mode (it asks for administrator rights once).
  • USB debugging is on: Settings > Device information > More information, press SoftLeft SoftLeft SoftRight SoftLeft SoftRight SoftRight, then Developer > Debugger > ADB.
  • No adb on this computer? On Windows, run winget install Google.PlatformTools in PowerShell or Command Prompt. On Linux, install it with your package manager, for example sudo apt install adb.

A raw copy of the whole eMMC is about 29 GB on a new device. Backing up just the partitions that the OTA patch touches is about 4 GB.

  1. Turn the phone off.
  2. Hold Volume Up and Volume Down together and keep holding while it starts. The screen will go white, or prompt a keypress.
  3. Connect, then save the backup. The full backup can take a while.

connect the phone to see the otas for its build

The phone took the update. On the phone, confirm sideload ran into no errors and choose Reboot system now. The first boot may take longer than usual.

Restore a backup to the phone: a full eMMC image will take a long time, restoring a partial backup will restore only what the OTA patch touches.

  1. Put the phone in EDL mode, and connect.
  2. Pick the backup. The page shows what it will write.
  3. Tick the box and write it. Leave the phone plugged in until it says done.

the phone isn't in the list

The browser lists it by TCL's name for it, PITTI-QRD, not Flip 4 or T440W.

Plug the phone in with a cable that carries data, and check USB debugging is on.

On Windows the browser needs the phone's adb driver (WinUSB). If adb devices lists the phone, you have it. If not, install the Google USB Driver.

Linux may need a udev rule to access the device.

the phone in edl mode isn't in the list

In EDL mode the phone is a Qualcomm 9008 device (USB 05C6:9008).

On Windows that takes the WinUSB driver. If the list is empty, run the driver helper, which puts WinUSB on it.

Linux may need a udev rule for 05c6:9008.

Only one program can use EDL mode at a time, so make sure nothing else is using it.

it doesn't find the phone in sideload mode

In sideload mode the phone is a new USB device to the browser, listed as T440W instead of PITTI-QRD, so the first time you pick it again: press "pick the phone in sideload mode". After that the browser remembers it.

You can also sideload the patch yourself with adb sideload ota.zip.

failed flash and won't boot

A failed flash leaves the old slot to boot from, and the phone goes back to it after about 10 failed boots. If it doesn't switch back on its own, write your backup in EDL mode. If you didn't make a backup, ask on the KaiOS Discord server; you can probably get help there.
